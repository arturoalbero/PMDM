# What Do We Mean by Cross-Platform Applications?

When we talk about cross-platform applications, we are referring to applications that are developed using a single programming language and that facilitate their export and execution—with minimal changes—on any device, regardless of the operating system.

On the other hand, there are native applications, which are developed specifically for each system, using their own specific languages and technologies. A clear example of this is the Swift programming language, created by Apple for developing applications for iOS, Mac, or Apple TV, or Kotlin, for developing applications for Android.

# Approaches to Cross-Platform Development

In order to minimize platform-specific development and the cost that this entails, various technologies have emerged, focused mainly on web technologies. Within these, we have a wide range of possibilities:

* **Responsive web applications**: These are applications based on web technologies: HTML, CSS, and JavaScript, which adapt their interface to any device (*responsive* design). These applications do not require any native development, since they run directly in the system's web browser. Therefore, we have a single codebase, but these applications do not offer as smooth a user experience as native applications, nor do they allow access to all system components, such as the hardware itself.
* **Hybrid applications**: These are responsive web applications that are loaded inside a *WebView*-type component of the system, which is essentially a browser without the navigation bar, giving it the appearance of a native application. These applications also allow access through the *WebView* to some device features, such as location or the accelerometer. The most popular framework for developing hybrid applications is *Ionic*, which allows development using other web frameworks such as *React*, *Angular*, or *Vue*.
* **Progressive Web Applications (PWAs)**: PWAs are still web applications, but thanks to certain components, such as *Service Workers* and other technologies, they are closer to native applications. This allows them to make better use of their potential, accessing hardware, working with limited or no connectivity, or providing system notifications. There are several frameworks for developing PWAs, including *React PWA Library*, *Angular PWA Framework*, *Vue PWA Framework*, *Ionic PWA Framework*, *Svelte*, *PWA Builder*, and *Polymer*.

As mentioned, these three types of applications are based on the use of web technologies and some component, either the browser itself or a *WebView*. Although there are very good applications based on these technologies, they do not achieve the native experience in terms of smoothness and functionality.

A step further in cross-platform development is represented by frameworks that, starting from the same codebase, generate applications compiled natively for different operating systems. Some of the most widely used technologies for this type of application are:

* **React Native** and **NativeScript**: These use the JavaScript programming language as their foundation, but instead of building interfaces using HTML, they use framework-specific components that are compiled into native code, making it unnecessary to use a WebView as an intermediary.
* **Flutter**: This framework, created and maintained by Google, enables the development of cross-platform applications using the *Dart* language. These applications are compiled into native code for different operating systems such as Android, iOS, Linux, Windows, and even the web. Flutter is also the native technology of the Google Fuchsia operating system, an attempt by Google to create a natural replacement for Android, based on its own *Zircon* microkernel. It is currently used in IoT devices, and its development has slowed down considerably.
