# Visual Studio Code

For code editing, we will use [Visual Studio Code (VSCode)](https://code.visualstudio.com/), a lightweight, cross-platform editor with a large number of extensions that will help us develop Flutter applications. VSCode is the most recommended editor for Flutter, as it is extremely flexible and adapts to the developer's needs through specific extensions.

If you already have Visual Studio Code installed on your computer, you can skip this installation section and go directly to the [section on installing the required extensions](https://joamuran.net/flutter2026/u1/3.VSCode/).

## VSCode Download and Installation

We can download VSCode from the [official VSCode download website](https://code.visualstudio.com/Download), where packages for several operating systems are available. Simply select the appropriate package for Windows, macOS, or Linux and follow the installation instructions.

## Installation on Ubuntu and Derivatives

If we want to install *Visual Studio Code* on *Ubuntu* or a derivative distribution, we can choose to download the `.deb` package directly [from the official VSCode website](https://code.visualstudio.com/docs/setup/linux#_debian-and-ubuntu-based-distributions) and install it easily using the command line.

We download the `.deb` file and install it with:

```text
$ sudo apt install ./<deb_file>.deb
```

**Warning!**

If we are using an older version, it may be necessary to use `dpkg` in the following way:

```text
sudo dpkg -i <deb_file>.deb
sudo apt-get install -f  # Install the remaining dependencies
```

**Updates**

When we install the `.deb` package, the system will automatically add Microsoft's repositories for automatic updates. This way, VSCode will be kept up to date through the system's own package management system.

**More information...**

More information about installing VSCode is available in Microsoft's official documentation:

* https://code.visualstudio.com/docs/setup/linux
* https://code.visualstudio.com/docs/setup/windows

### Flutter Integration with Visual Studio Code

Visual Studio Code is a lightweight and highly flexible code editor. Through extensions or plugins, VSCode can become a very powerful development environment for Flutter. The essential plugins you will need for Flutter development are:

**Flutter**: Provides full support for Flutter development, including application creation, execution, debugging, and hot reload.

![Flutter Extension for VSCode](https://joamuran.net/flutter2026/u1/img/3.VSCode/flutte_extenision.png)

**Dart**: Adds support for the Dart language, with tools for editing, debugging, and syntax highlighting. The Flutter extension already includes this as a dependency.

![Dart VSCode Extension](https://joamuran.net/flutter2026/u1/img/3.VSCode/dart_extension.png)

**Optional extensions to improve the workflow**

**Pubspec Assist**: Makes it easier to manage dependencies in Flutter's `pubspec.yaml` file, allowing dependencies to be added quickly.

![Pubspec Assist Extension for VSCode](https://joamuran.net/flutter2026/u1/img/3.VSCode/pubspec_extension.png)

**Awesome Flutter Snippets**: Provides a rich set of snippets (code fragments) to speed up the creation of components and functionality in Flutter.

![Awesome Flutter Snippets Extension](https://joamuran.net/flutter2026/u1/img/3.VSCode/awesome_snippets.png)

Although there are more comprehensive extension packs, with these extensions installed, Visual Studio Code will be fully prepared for Flutter development.

# Extra! Flutter Integration with Android Studio

We can also use Android Studio for Flutter development. To do this, we need to install the Flutter plugin for Android Studio, which can be found in the Settings menu (*Settings* from the gear icon on the welcome screen), within the *Plugins* section. This plugin will require the Dart plugin for Android Studio, as indicated during its installation:

![Flutter Plugins for Android Studio](https://joamuran.net/flutter2026/u1/img/3.VSCode/android_studio.png)

With this, we will have the option to create new Flutter projects directly from the welcome screen.

One advantage of this IDE is that, since it is more closely integrated with the emulator, it makes debugging our applications easier. In addition, if we work with more complex Android projects, it is worth remembering that this is the official IDE for the system, and it can be useful if we need to modify the Android project structure.
