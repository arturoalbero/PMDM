# Flutter SDK Installation

At this point, we will look at the installation of the Flutter SDK, following the instructions from the official documentation.

In order to develop applications for Android, Flutter requires a complete installation of Android Studio, as it needs the Android SDK and several of its components.

Therefore, as a preliminary step, we will see how to install this IDE.

If you already have an installation of Android Studio on your computer, you can go directly to the [final configuration](https://joamuran.net/flutter2026/u1/2.InstalacioFlutter/#ajustos-finals) to install the components required by Flutter.

## 1. Android Studio Installation

As mentioned, Flutter requires several components of the Android SDK, so the most convenient approach is to perform a complete installation of it.

To do this, we will follow these steps.

1. We access the [Android Studio page from the IDE page](https://developer.android.com/studio?hl=es-419) and click the button to download the latest version (in the image, "Download the AndroidStudio Otter 3 feature update").

[Android Studio Download](https://joamuran.net/flutter2026/u1/img/2.SDK/android_studio_1.png)

1. By doing this, we accept the licenses and download the compressed IDE file (on Linux) or the installer on Windows:

[Android Studio Download](https://joamuran.net/flutter2026/u1/img/2.SDK/android_studio_2.png)

The installation on Windows follows a fairly standard process, so at this point we will focus on the installation on Linux.

1. The compressed file we have downloaded contains the complete IDE for Linux, including the binaries, the IntelliJ libraries on which Android Studio is based, etc. Therefore, what we need to do is extract it into the folder where we want to have the installation. For example, we can create a `devtools` folder in our user directory and extract it there. We would then have a structure like this:

```text
~
└── devtools
    └── android-studio
        ├── bin
        │   ├── ...
        │   ├── studio
        │   ├── studio64.vmoptions
        │   ├── studio.png
        │   ├── studio.sh
        │   ├── ...
        │
        ├── build.txt
        ├── Install-Linux-tar.txt
        ├── ...

```

1. Once the folder has been extracted, we can run the IDE either through the `studio.sh` script or directly through the `studio` binary, which acts as a wrapper for `studio.sh`.

Note that on Linux, the Android Studio IDE is not distributed as a software package (.deb, .rpm...), but rather as a compressed file that we simply need to extract and run. During the first execution, we will complete the environment configuration and download the necessary SDK components.

### Android SDK Installation

The first time we run Android Studio, it will ask us for some initial configuration settings, such as the type of installation (standard/custom), the theme we want (light/dark), licenses, and some details about the emulator and the components to be installed. We will choose a standard installation and accept all the required licenses.

In the case of GNU/Linux systems, the wizard tells us that we can configure Hardware acceleration (KVM) for the Android emulator, and it guides us through this process.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_1.png)
![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_2.png)
![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_3.png)
![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_4.png)

Once Android Studio has been configured, the different SDK components (build tools, platforms, emulators, etc.) will begin to download. This SDK is stored in a different folder from Android Studio itself (by default, in `~/Android/Sdk`).

### Final Configuration

Once the SDK component download is complete, the Android Studio welcome window will be displayed. From this window, we could already create native Android projects. For now, we are only interested in making a couple of configuration changes:

* First, we are going to create a shortcut to the IDE so that we do not have to access the executable directly through the command line. To do this, click the gear icon in the bottom-left corner of this screen and select the "Create Desktop Entry" option.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_5.png)

* We will now take advantage of having Android Studio open to install a component that we will need for Flutter: the command-line tools, or *Command Line Tools*. To do this, locate the *More Actions* dropdown and, inside it, look for *SDK Manager*, which is the IDE component that helps us manage the SDK.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_6.png)

In this section, we will need to look for the *Language And Frameworks* > *Android SDK* > *SDK Tools* option, and within it select *Android SDK Command Line Tools (latest)*. Select the option and click *Apply* or *OK*.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_7.png)

### Emulators

Finally, before leaving this Android Studio screen, we can open the virtual device manager (*Virtual Device Manager*) from the *More Options* tab and check that an emulated device has already been created as part of the installation.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_8.png)
![image](https://joamuran.net/flutter2026/u1/img/2.SDK/android_9.png)

Now we can continue with the installation of the Flutter SDK itself.

## 2. Flutter SDK Installation

To install Flutter on our system, the recommended approach is to follow the steps in the [official Flutter documentation](https://docs.flutter.dev/get-started/install). Here we will look at a general description of the process and the development environment configuration.

### Required Tools

In addition to Android Studio, some tools such as *git* and system libraries are required. Let's see how to perform this installation.

On the [official Flutter installation documentation page](https://docs.flutter.dev/get-started/install), we select the recommended ***Quick start*** option to make the installation as straightforward as possible.

![image](https://joamuran.net/flutter2026/u1/img/2.SDK/sdk_quick_start.png)

From here, we select the operating system on which we want to perform the installation. If we look closely, the website already detects which system we are working on and preselects it for us. In this section, we will review the steps for **Linux** and **Windows**.

![Operating System Selection](https://joamuran.net/flutter2026/u1/img/2.SDK/SDK1.png)

This provides us with instructions for installing the basic software we need before installing the SDK.


As indicated [in the documentation](https://docs.flutter.dev/install/quick#download-prerequisites), in order to prepare the system we will need:

* The [Git for Windows](https://gitforwindows.org/) tool to manage Flutter versions, and
* Android Studio, which we have already installed in the previous section.
