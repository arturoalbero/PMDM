# The Dart Language

The language used for development in Flutter is Dart, so before diving into programming with the framework, we will familiarise ourselves with it a little.

To work with the different examples we will see in this unit, we only need to write them in a text file with the .dart extension and run them using:

```
$ dart filename.dart
```

Alternatively, we can also work with the [Dart Playground](https://dartpad.dev/) . This has the advantage of including, in the same window, a code editor with syntax highlighting and error detection, the program output, documentation, and some examples in both Dart and Flutter, allowing us to explore their different possibilities.

## Basic Concepts

Like many other programming languages, Dart uses the `main` function as the entry point to a program. We will start with a classic Hello World example with input parameters:

```
void main(List<String> args){
  // Hello World example
    if (args.isNotEmpty) {
      print ("Hello ${args[0]}");
    } else  {
      print("Hello world!");
    } 
}
```

> Warning
>
> The code above uses a list of input arguments (`args`), so it cannot be executed directly in the Dart Playground.

One way to emulate arguments in the Playground is to declare them directly in the code as a `List<String>`:

```
 void main() {
   List<String> args = ['User'];
   ...
 }
```

Let's look at some details of Dart in this code:

* The `main` function does not return a value. Although specifying the `void` type is not mandatory, it is generally considered good practice to do so.

* This main function can receive arguments in the form of a list of strings (`List<String> args`). If we do not need arguments, we can simply use `void main()`.

* To check whether the list is empty, although we could check whether its length is greater than zero (`args.length>0`), it is more appropriate to use `isNotEmpty`.

* Code blocks must be enclosed in curly braces `{}`. When a block consists of only one line of code (as is the case with the two `print()` statements in the example), it is also recommended to use braces, even though they are not mandatory.

* Comments are expressed as in other languages such as Java or C, using `//` and `/* ... */`, depending on whether they are single-line or multiline comments.

* To display a message on the screen, we use the `print()` statement. When there are variables within the text, although we can use the `+` operator to concatenate string literals, the use of string interpolation is recommended. This uses the `$` symbol (`$variable`) or `${}` when we need to delimit the interpolation (`${variable.property}`), just as we do in Bash.

* Dart statements end with a semicolon `;`.

* We can access lists directly using the `[]` operator, as if they were arrays.

> Note
>
> About multiline comments
>
>One aspect to bear in mind regarding multiline comments is that they must always be opened and closed in the correct order. For example, the following code:

```
void main() {
  print("hello");
  /*print("hello");
  /* print("hello"); */
}
```

Would produce the following error:

```
prova.dart:3:3: Error: Comment starting with '/*' must end with '*/'.
  /*print("hello");
  ^
prova.dart:1:13: Error: Can't find '}' to match '{'.
void main() {
```

Therefore, the comment would need to be explicitly closed:

```
void main() {
  print("hello");
  /*print("hello");
  /* print("hello"); */*/
}
```

## Input and Output

As we have seen, we can use the `print()` function to display messages in the console, but this is not the only way.

Dart provides mechanisms for managing input and output through the console and keyboard, among other things, through the dart:io library. Specifically, for console output, it provides the `.write()` method of the `stdout` and `stderr` classes, corresponding to standard output and error output, respectively. For keyboard input, we can use the `.readLineSync()` method of the `stdin` class.

Let's look at a short example:

```
import 'dart:io';

void main(){
  stdout.write("Hello! What's your name? ");
  var name=stdin.readLineSync();
  print("Hello $name!");
}
```

The output of this program will be as follows:

```
$ dart example.dart 
Hello! What's your name? Jose 
Hello Jose!
```

As you can see, the main difference between the `stdout.write` method and `print` is that the former does not add a line break at the end, whereas `print` does.

It is worth noting that the `Stdin` class allows users to read data from standard input both synchronously and asynchronously. As we have seen, to read input from the keyboard synchronously, we use the `readLineSync()` method.


# Variables and Data Types

The data types supported by Dart are:

* Numeric types: integers (`int`) and decimals (`double`).

* Strings: `String`.

* Logical values: `bool`.

* Object collections: Lists (`List`), Sets (`Set`), and Maps (`Map`).

To declare a variable in Dart, we can use `var`, so that the data type is inferred automatically from the given value, or we can specify the type directly. Once a type has been assigned to a variable, it cannot be changed. Let's look at some examples:

dart

```
var day = 'Thursday';       // Infers the String type
String day = 'Tuesday';     // Define a String
int number = 42;            // Define an integer
bool workingDay = true;     // Define a logical value

// We can also perform type conversions
String numberString = "1";               // Define a String containing a number
int number2 = int.parse(numberString);   // Convert the string "1" to a numeric type
```

## Constants and final

To define constants, we use the reserved keyword `const`, which declares a value at compile time that will be immutable and cannot be reassigned:

dart

```
const course = 'Flutter';
```

We can also declare data as `final` to indicate that it cannot be reassigned. The difference between constants and final variables is that an object declared as final**, although it cannot be reassigned, is still mutable**. In other words, its internal properties can still be changed.

For example, if we define a list as a constant, we will not be able to add elements to it. However, if we declare it as final, although we cannot assign another list to it, we can still add elements.

runtimeType

To check the type of an object, we can use its `runtimeType` property.

For example:

dart

```
void main() {
  var a = 1;
  print(a.runtimeType);     // -> Prints "int"
}
```

## Null Safety and Handling Null Values

Dart is a type-safe language, which means that when we declare a variable of a particular type, the compiler guarantees that the assigned values are of that type. Although typing is mandatory, specifying a variable's type is optional. If we do not specify the type, it will be inferred from the value used to initialise it.

Since version 2.12 (March 2021), Dart has also supported Null Safety, meaning that, by default, a variable cannot contain null values unless explicitly specified otherwise. This helps avoid problems arising from null values.

Let's look at the different operators used to handle null values in Dart:

* Nullable value declaration (`?`): If we want to explicitly indicate that a variable can contain null values, we use a question mark in its declaration, as is done in other languages such as Kotlin:

  dart

  ```
  int? variable1; // variable1 can contain the null value
  ```

* Null assertion operator (`!`): This is used when we want to assign a variable that may contain null values to a variable that cannot contain them.

  dart

  ```
  int variable2 = variable1!;
  ```

  Example:

  dart

  ```
  int? variable1;
  int variable2 = variable1!; // TypeError: null has no
  print(variable2);           // propertiesError: TypeError:
                              // null has no properties
  ```

* The error above stops the program from executing. To handle exceptions that occur, we can use try-catch blocks, as in other programming languages.

  dart

  ```
  int? variable1;
  try {
    int variable2 = variable1!;
    print(variable2);
  } catch (e) {
    print(e.runtimeType); // -> NullError
    print(e);             // -> NoSuchMethodError: t1 is null
  }
  ```

* Null coalescing operator (`??`): This operator returns the value resulting from the expression on the left-hand side of the operator, provided it is not null. Otherwise, it returns the expression on the right. We can think of it as a kind of conditional operator for null values:

  dart

  ```
  var name;
  // Prints the name if it is not null, or prints "Anonymous"
  print(name ?? "Anonymous");
  ```

* Null-aware assignment (`??=`): Assigns a value to a variable if that variable is null. If the variable already has a value other than `null`, no assignment takes place.

  dart

  ```
  int? variable1;   // Would cause an error if nullable were not specified
  print(variable1); // Prints null
  variable1 ??= 10;
  print(variable1); // Prints "10"
  variable1 ??= 15;
  print(variable1); // Prints "10", since variable1 already had a value
  ```

* Null-aware access (`?.`): Prevents an exception from being thrown when accessing a property or method of an object that may be null.

  dart

  ```
  String? string;
  print(string?.length);
  ```

## The `dynamic` Type

Dart is a language that supports both static and dynamic typing. Static typing refers to assigning types at compile time, meaning that the variable type must be specified in the declaration itself, as we have seen so far. However, Dart also supports dynamic typing, which performs type checking at runtime.

For this purpose, Dart uses the `dynamic` type, a type underlying all Dart objects that allows us to use dynamic typing. This means that type checking is performed at runtime rather than at compile time.

You can find more details in the article [Dart is a Static or Dynamic Typed Programming Language](https://medium.com/@farhanaslam910/dart-is-a-static-or-dynamic-typed-programming-language-3d934c95b7b) .

Warning!

Keep in mind that we should not overuse dynamic typing. It is always better to try to avoid it in order not to lose the benefits of type safety.

## Enumerated Types

Enumerated types in Dart (`enum`), as in other programming languages, are used to represent a fixed number of constant values.

For example, we can define an enumeration containing the days of the week:

dart

```
enum Weekday { monday, tuesday, wednesday, thursday, friday, saturday, sunday }
```

Internally, each of these values is represented by its index, with the first value being 0.

To access these values, we use dot notation. For example:

dart

```
Weekday day = Weekday.monday;
```

If we want to obtain a list containing the enumeration values, we use `values`:

dart

```
List<Weekday> days = Weekday.values;
```

Note

An enumerated type, just like a class, must be defined outside any function or class.

# Structured Programming

Structured programming in Dart is based on the usual conditional and repetition structures: if..else, switch, for, forEach, and while. It also supports the ternary conditional operator (`?`).

Let's look at some commented examples of these structures:

# Conditional Structures

* Example 1: The `if`/`if-else` statement

dart

```
// Import the dart:io library, which contains
// the definition of the exit function
import 'dart:io';

// The main function checks whether it has
// received an argument when invoked
void main(List<String> args) {
  // Simple if example
  if (args.length != 1) {
    print("Error, an argument must be provided");
    exit(1);
  }

  // Get the value of the first argument
  // Use a try-catch block in case
  // a type-related exception occurs

  var temperature;
  try {
    temperature = int.parse(args[0]);
  } catch (e) {
    print("An exception occurred: ${e.toString()}");
    exit(1);
  }

  // if-else example
  // Although not required, it is recommended
  // to always use curly braces {}

  if (temperature > 21) {
    print("It's hot");
  } else {
    print("It's cold");
  }

  // Ternary conditional operator example
  temperature > 21 ? print("It's hot") : print("It's cold");

  // Abbreviated if as an expression (assigned to a variable)
  var text = temperature > 21 ? "It's hot" : "It's cold";
  print(text);
}
```

To run the previous example (if we have named it example1.dart), we use:

Bash

```
$ dart example1.dart temp
```

Where temp is a numeric value representing a temperature.

* Example 2: The `switch` statement

dart

```
// Import the dart:io library, which contains
// the definition of the exit function
import 'dart:io';

// The main function checks whether it has
// received an argument when invoked
void main(List<String> args) {
  if (args.length != 1) {
    print("Error, an argument must be provided");
    exit(1);
  }

  // switch example
  var weekday = args[0];

  // Use the toLowerCase method on
  // strings to convert everything to lowercase.
  switch (weekday.toLowerCase()) {
    case "saturday":
    case "sunday":
      print("It's not a working day");
      break;
    default:
      print('It is a working day or an invalid day');
  }
}
```

Notice that the way it works is the same as in other languages such as Java: when the value being evaluated by the `switch` matches one of the `case` labels, its contents are executed until a `break` is encountered. In this way, we check whether the day is Saturday or Sunday, and execute the same block in both cases.

# Repetition Structures

* Example 1: Using `for`

dart

```
void main(List<String> args) {
  // for example
  for (int i = 0; i <= 10; i++) {
    // Check whether it is even
    if (i.isEven)
      print("${i} is even");
    else
      print("${i} is odd");
  }
}
```

* Example 2: The `while` loop

dart

```
// while example
void main(List<String> args) {

  // Requires initialisation
  // before the loop
  int i = 0;
  while (i <= 10) {
    if (i.isEven)
      print("${i} is even");
    else
      print("${i} is odd");
    i++;
  }
}
```

* Example 3: The `do..while` loop

dart

```
void main(List<String> args) {
  // Initialisation beforehand
  int j = 0;

  do {
    // The loop body will execute
    // at least once.

    if (j.isEven)
      print("${j} is even");
    else
      print("${j} is odd");
    j++;
  } while (j <= 10);
}
```
