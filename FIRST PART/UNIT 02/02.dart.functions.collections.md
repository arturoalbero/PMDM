# Functions in Dart

# Function Declaration

Dart supports first-class functions, that is, functions that are not bound to an object as methods.

Function declarations are very similar to those in other languages such as C or Kotlin:

* Function without arguments and without a return value


```dart
void function() {
  // Function body
}
```

* Function with arguments and without a return value

  ```dart
  void function(type1 argument1, ..., typeN argumentN) {
    // Function body
  }
  ```

* Function with arguments and a return value


```dart
returnType function(type1 argument1, ..., typeN argumentN) {
  // Function body
  return valueOfReturnType;
}
```

# Anonymous Functions and Arrow Functions

Dart supports functions without names, or anonymous functions, which cannot be invoked directly but can be used as callbacks, that is, as arguments to other functions.

For example, let's define a function (`function`) that receives three arguments: the first two (`arg1` and `arg2`) are values, and the third is an anonymous function (`callback`). The body of this `function` invokes the function provided as an argument and returns the value it produces:


```dart
// Function that receives two arguments and an
// anonymous function that acts as a callback
int function(arg1, arg2, callback) {
  int value = callback(arg1, arg2);
  return value;
}
```

In this code, we are invoking a function that we receive as a parameter within the body of another function. Although the function we receive is anonymous, since we have received it as an argument, we use the argument's name (`callback`) to invoke it.

Now, we can use this function by providing it, at the time of invocation, with the functionality we want it to perform, through an anonymous function:


```dart
void main() {
  int value = function(3, 4, (arg1, arg2) {
    // We are inside the anonymous function
    return (arg1 + arg2);
  });
  print(value);
}
```

As we can see, the anonymous function receives two arguments and returns their sum.

## Arrow Functions

Arrow functions allow us to abbreviate the declaration of an anonymous function when it consists of only one line, so they do not use curly braces or the reserved keyword `return`.

The previous example could have been expressed using arrow functions as follows:


```dart
int function(arg1, arg2, callback) => callback(arg1, arg2);

void main() {
  print(function(3, 4, (arg1, arg2) => arg1 + arg2));
}
```

# Required Positional, Optional Positional, and Named Arguments

Functions in Dart support three types of arguments:

* Required positional arguments.

* Optional positional arguments, which we specify using `[]` and which may or may not have a default value (if none is specified, the value will be `null`).

* Optional named arguments, which we specify using `{}` and for which the name must be specified when invoking the function. It is worth noting that, for this type of parameter, the order in which they are specified in the invocation does not matter.

Let's look at some examples:


```dart
void f1(int required, [int optional = 0]) {
  print("${required}, ${optional}");
}

void f2(int required, {int optionalNamed = 0}) {
  print("${required}, ${optionalNamed}");
}

void main() {
  f1(1);    // Prints: 1, 0
  //f1();   // If we call f1() without arguments, we will get
            // the error: Context: Found this candidate,
            // but the arguments don't match.

  f1(1, 2); // Prints: 1, 2

  f2(1);    // Prints: 1, 0

  // f2(1, 2); // If we provide two arguments to f2, but
              // without specifying the name, we will get
              // an error again.

  f2(1, optionalNamed: 3); // Prints: 1, 3
}
```

When a function call, an object method call, or a constructor uses several named arguments, it is common to place the different parameters on separate lines. For example:


```dart
functionX(
    parameter1: value1,
    parameter2: value2
    ...
)
```

As we will see later, this will be a very common construct when we create visual components with Flutter.

# Collections

Collections are objects that represent a group of elements and can have different structures and behaviours. The most common collections are lists, sets, and maps.

# Lists

Dart follows the principle of same level of abstraction, according to which clean code should not mix high-level instructions with low-level instructions when implementing its logic, making the code easier to read.

Dart can be defined as a high-level language that does not rely on low-level structures such as arrays, but instead directly uses lists (the `List` class) to represent ordered collections of elements.

However, Dart makes it possible to access lists as if we were working with arrays, while also providing higher-level functions that allow us to work more conveniently.

## Creating Lists

Let's look at some ways to define lists:


```dart
// Null list
List nullList;

// Empty list
List emptyList = [];

// Empty list specifying the type
List<String> emptyList = [];      // Form 1
List<String> _list = <String>[];  // Form 2

// List with values
List weekdays = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday'];

// List with values specifying the type
List<String> holidays = ['Saturday', 'Sunday'];
```

## Manipulating Lists

Now let's look at some ways to access and manipulate them:


```dart
// Accessing an element at a position
print(weekdays[3]);

// Adding elements to the list
emptyList.add("Element");

// Modifying an existing element in the list
// Warning! This element must exist! This does not add elements!
emptyList[0] = "Element 2";

// Removing the last element from the list
weekdays.removeLast();

// Removing an element at a specific position in the list
weekdays.removeAt(position);

// Appending an entire list to another list
List daysOfWeek = [];
daysOfWeek.addAll(weekdays);
daysOfWeek.addAll(holidays);
print(daysOfWeek);
```

In this last case, in order to use `addAll`, the list must be initialised (that is, it must not be null). If we had defined this list as `List daysOfWeek;`, we would have received an error.

# Sets

Another interesting collection of elements in Dart is Sets, which, unlike lists, do not keep elements indexed and therefore prevent duplicate elements.

Let's look at some examples of how to define and work with sets:


```dart
// Declare a set from a list
var modules = Set.from(["PMDM", "AD", "PSP", "DI", "SGI"]);

// To add elements, use add:
modules.add("EIE");

// Remove elements using remove:
modules.remove("EIE");

// To check whether an element exists in the set, use contains
print(modules.contains("EIE"));
```

# Maps (Dictionaries)

A dictionary is a data structure that stores key-value pairs, in a similar way to JSON.

Let's look at some examples of how to define and work with these structures:


```dart
// Define a map and assign values
Map grades;
grades = {"PMDM": 8, "AD": 9, "PSP": 9, "DI": 7};

// Accessing values
print(grades["PMDM"]);
grades["DI"] = 9;

// Define a map specifying the types:
Map<String, int> map2;

// Define a map specifying a dynamic type for the values
Map<String, dynamic> map3;

// Adding new elements to the map
// If the key already exists, its value is modified
grades["EIE"] = 10;

// Removing elements
grades.remove("PMDM");

// To check whether an element exists
print(grades.containsKey("PMDM"));
```

# Traversing Data Structures

To traverse the different structured data types, we can use `for` loops with the `in` operator, or the `forEach` method.

## Traversing Lists

If we define the following list, for example:

```dart
List weekdays = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday'];
```

We can traverse it using a `for..in` loop as follows:


```dart
for (String day in weekdays) {
  print(day);
}
```

And using a `forEach` loop as follows:

```dart
weekdays.forEach((day) {
  print(day);
});
```

The `forEach` method receives an anonymous function as an argument, which is invoked for each element in the list. This anonymous function receives the element in question as an argument and processes it within its body. In this case, the processing consists of printing the value.

Alternatively, the anonymous function we provide to the `forEach` method could also be expressed as an arrow function, as follows:


```dart
weekdays.forEach((day) => print(day));
```

## Traversing Sets

Sets are traversed in the same way as lists. If we define the following set from a list:


```dart
Set weekdays =
    Set.from(['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday']);
```

We can traverse it using a `for..in` loop as follows:


```dart
for (String day in weekdays) {
  print(day);
}
```

And using `forEach` with an arrow function:


```dart
weekdays.forEach((day) => print(day));
```

## Traversing Maps

Now let's define a dictionary containing modules and their grades:


```dart
Map<String, int> grades = {"PMDM": 8, "AD": 9, "PSP": 9, "DI": 7};
```

To traverse this dictionary using a `for..in` loop, we use the map's `keys` property, which provides us with a collection of its keys. To display the grades for each module, we access the corresponding value in the dictionary:


```dart
for (String module in grades.keys) {
  print("Module: $module, grade: ${grades[module]}");
}
```

As for the `forEach` method of dictionaries, it receives two arguments instead of one: the key and the value of each element. Therefore, to display its contents, we would write:


```dart
grades.forEach((key, value) => print("Module: $key, grade: $value"));
```

# Mapping Data Structures

Collections in Dart have a `map` method for transforming one structure into another. To do this, we need to provide an anonymous function that will be applied to each element to obtain the corresponding new element.

Let's look at an example of how to convert a set of uppercase Strings into a collection in which they are expressed in lowercase.


```dart
void main() {

  // Define a set of elements
  var modules = Set.from(["PMDM", "AD", "PSP", "DI", "SGI"]);
  print(modules);

  // Now use the map method to process
  // each element in the set
  // (In this case, we convert them to lowercase)
  var modules2 = modules.map((item) {
    return item.toString().toLowerCase();
  });

  print(modules2);
}
```
