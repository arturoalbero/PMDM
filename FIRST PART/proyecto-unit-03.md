# Mini proyecto parecido al examen.

## Crea una aplicación en flutter que tenga las siguientes características (8 puntos)

Tres pantallas, cada una con un número que indique cuál es de forma visual. El número que aparezca centrado en la pantalla.
    - En la pantalla 1, haz que el fondo sea de color rojo. (1 punto)
    - En la pantalla 2, incluye un botón y un contador que sume 1 cada vez que se pulse. No hace falta que se guarde el contenido cuando se cambie de pantalla. (1 punto)
    - En la pantalla 3 harías cosas de UNIT 04. (2 puntos)

Una barra de aplicación con un menú para navegar de una pantalla a otra. 
    - Haz una versión con Navigator. Usa push para ir a una ventana y pop para volver. (2 puntos)
    - Haz otra con go_router. (1 punto) 
    - En la de Go Router, mete la barra de aplicación en el Shell (Ten en cuenta que en el examen, parte del código de la barra de navegación lo tendrías dado). (1 punto)
